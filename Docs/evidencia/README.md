# Verificación móvil de búsqueda y detalle

Capturas tomadas en Chrome con una ventana de 393 × 852 px, usando respuestas simuladas de la API para mostrar 25 resultados. Incluyen búsqueda y ficha en modo claro y oscuro. En ambos casos se comprobó que no hubiera desborde horizontal.

En la ventana de escritorio (1280 × 600 px), se abrió una tarjeta tras bajar la lista a 800 px: la ficha apareció en 0 px y «Atrás» restauró la lista a 800 px sin repetir la consulta de búsqueda.
